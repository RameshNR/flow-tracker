Flow Tracker helps you follow a code path through a Java, Kotlin or Java web project (JSP, JavaScript, TLD and more). While you read code, click the lines that matter. Flow Tracker collects them in a side panel, keeps them in call order automatically, and copies the whole flow as text, a compact log or a Markdown document.

Collect lines while you read

  • Hover any line and click the + in the gutter to save it, together with its file, class, method, line number and project. Works in Java, Kotlin, Groovy, JSP / tag files, JavaScript / TypeScript (JS, JSX, TS, TSX), TLD, XML, HTML, properties, YAML and SQL files.
  • Add to Flow Tracker from the editor's right-click menu or Ctrl+Alt+Shift+A: the caret line or every selected line, as one undo step.
  • Record with the debugger: every line where it stops (breakpoints and steps) is added in the order it runs.
  • Saved lines show their step number in the gutter, with the method and note on hover, and follow your edits in both views. Click the number to remove the line.
  • Add Bottom ↓ / Add Top ↑ chooses where new lines go.
  • Undo / Redo revert adding, deleting and clearing lines.
  • Recycle Bin: everything you delete (lines, cleared and deleted flows) can be restored later.

Named flows you can share

  • Keep several named flows per project (e.g. Flow 1: Checkout bug), switch between them, and drag them into the order you want.
  • Export a flow as a .flow.json file (paths relative to the project) to commit or send, and Import it on any machine.
  • Copy All Flows switch: the Copy button copies every flow in one go.
  • Open Markdown opens the flow as a Markdown file with the preview, diagrams included.

Two views

  • Grouped View: file → method → lines, with line numbers, syntax colors and a project tag on each file, so files with the same name in different projects can't be confused.
  • Flat View: one numbered sequence in flow order.
  • Search to show only matching lines (code, file, method, note or tag).

Work with rows

  • Hover action bar on every row: ↑ ↓ move | Copy, Note | Delete. It shows only the buttons the row needs, and sticks to the visible edge when the code is long, so no scrolling is needed.
  • Drag and drop files, methods and lines to reorder them.
  • Right-click menu: Move Up/Down, Copy, Add/Edit Note, Jump to Source, Walk from Here, Tag, Delete.
  • Double-click a line to jump to it. Ctrl+C copies, Delete removes.
  • Tags: mark lines as Bug, Important or Question.
  • Lines that no longer match the code get a warning and can be re-linked in one click.
  • Connect Call To: join a line by hand to the method it reaches when the code can't show it, such as an API call handled in another project.

Walk through the flow

  • Next Step / Previous Step (Alt+] / Alt+[) open each saved line in the editor in turn, with the step number, method and note in a hint. Great for code walkthroughs.

Sync: automatic call order

  • With Sync on, a method comes first and the methods it calls follow right after the calling line, across files: Java, Kotlin, Groovy, JSP pages calling Java, and JavaScript functions.
  • Moving anything by hand turns Sync off so your order is kept. One click re-sorts.

Copy the flow your way

  • Default: indented text (Grouped) or numbered steps (Flat).
  • Optimize Flat View Log: a compact [project] / file / method log with line | code rows.
  • Copy as Markdown: a .md document with a summary table, Mermaid diagrams of the real calls (flowchart or sequence diagram), each method's lines as a table with highlighted code, and the Original Log at the end, with each call nested under the line that makes it.

Good to know

  • Responsive toolbar: labels collapse to icons and wrap in narrow tool windows.
  • Follows your light or dark IDE theme. Settings → Info has all the help, with a screenshot carousel.
  • Data is stored per project in .idea/workspace.xml. Nothing leaves your machine unless you export a flow.
